# JWST Observation Map

This document explains how JWST fits into the examination system.

JWST measures infrared light. Atmospheric constituents are inferred from wavelength-dependent absorption or emission features.

## Useful JWST capabilities

### NIRSpec

Useful for near-infrared spectroscopy and molecular signatures in appropriate wavelength ranges.

### NIRISS

Useful for transmission spectroscopy of selected exoplanets.

### NIRCam

Can support transit and eclipse spectroscopy/photometry in suitable observing programs.

### MIRI

Provides mid-infrared observations and is especially relevant to longer-wavelength molecular bands.

## Observation record

For every planet studied with JWST, record:

- Target
- Planet
- JWST program ID
- Instrument
- Mode
- Start/end date
- Number of visits
- Transit/eclipse/phase observation
- Wavelength range
- Data product
- Published analysis
- Molecules searched for
- Molecules detected
- Upper limits
- Retrieval method
- Publication/reference

## Important limitation

JWST is not a dedicated "life detector."

Whether a molecular feature is observable depends on:

- host-star brightness
- planet radius
- atmospheric scale height
- transit geometry
- clouds/hazes
- spectral resolution
- number of visits
- stellar activity
- observing mode
- instrument sensitivity

## Future-proof design

The database must keep the telescope separate from the scientific question.

Example:

**Question:** Is CH4 + O2 chemical disequilibrium present?

**Observation source today:** JWST

**Possible future source:** Habitable Worlds Observatory or another mission

The scientific field stays the same even when the instrument changes.

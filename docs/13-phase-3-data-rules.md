# Phase 3 Data Rules

## 1. Selection is not interpretation

The K-dwarf census is an observational target population.

It is not a claim about life.

## 2. Keep missing measurements

Unknown mass, unknown stellar activity, or unknown atmospheric composition must remain explicitly unknown.

Do not convert missing measurements into exclusions.

## 3. Preserve provenance

PSCompPars is a composite population table.

When a scientific conclusion depends on a parameter, trace the parameter to the underlying literature reference where practical.

## 4. Keep JWST and MAST distinct

NExoList records approved JWST exoplanet observation counts.

MAST contains archival observation records.

Both are useful, but they answer different questions.

## 5. Separate observability and habitability

A planet can be easy to observe but not habitable.

A planet can be potentially habitable but difficult to observe.

Store those dimensions separately.

## 6. No premature ranking

Phase 3 is an inventory.

It should not produce a best-target list or a life score.

# Scientific Sources

This file records major authoritative references used to define the framework.

## Biosignature assessment

Catling et al. 2018 — *Exoplanet Biosignatures: A Framework for Their Assessment*

https://www.giss.nasa.gov/pubs/abs/ca07620h.html

Key contribution: system characterization, habitability context, biosignatures, corroboration, and false-positive exclusion.

## Biosignature false positives

Harman & Domagal-Goldman 2018 — *Biosignature False Positives*

https://www.giss.nasa.gov/pubs/abs/ha09810h.html

Key contribution: systematic treatment of abiotic processes that can mimic biological signatures.

## K-dwarf habitability context

NASA Science — *Stars in an Exoplanet World*

https://science.nasa.gov/exoplanets/stars/

NASA Science — *Goldilocks Stars Are Best Places to Look for Life*

https://science.nasa.gov/missions/hubble/goldilocks-stars-are-best-places-to-look-for-life/

These references support the project's use of K dwarfs as an important target population while not treating K-dwarf status as proof of habitability.

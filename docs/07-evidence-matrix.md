# Evidence Matrix

The evidence matrix is the project's main reporting tool.

It deliberately avoids a single "life score."

## Status vocabulary

Use exactly one primary status:

- **Observed** — measurement supports the feature
- **Not detected** — observation was sensitive to the feature but did not detect it
- **Upper limit** — a quantitative upper bound is available
- **Tentative** — feature is suggested but not established
- **Model dependent** — result depends strongly on assumptions
- **Unknown** — insufficient information
- **Needs observation** — a useful measurement has not yet been made

## Evidence hierarchy

A useful progression is:

**single spectral feature**

→ **repeat feature**

→ **multiple molecular features**

→ **chemically correlated features**

→ **planetary context**

→ **abiotic models challenged**

→ **independent confirmation**

No step is automatically sufficient.

## The most important question

For a candidate disequilibrium:

> **What source can continuously maintain this atmospheric state?**

Then ask:

> **Can a non-biological source maintain it at the observed abundance without producing other gases that should also be visible?**

That second question is the core of the abiotic challenge.

## Reporting template

### Observation

State only what the data show.

### Retrieval

State what atmospheric model produced the inferred abundance.

### Physical interpretation

Explain what the abundance implies about the atmosphere.

### Abiotic alternatives

List the viable non-biological pathways.

### Discriminating observations

State exactly what additional observation would distinguish the alternatives.

### Current conclusion

Use evidence language such as:

- consistent with
- inconsistent with
- not yet distinguishable
- difficult to reproduce with the tested abiotic models

Avoid:

- proof of life
- life detected

unless direct evidence beyond remote atmospheric inference actually exists.

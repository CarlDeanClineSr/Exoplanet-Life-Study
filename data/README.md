# Data Directory

This directory is reserved for structured study data.

## Rules

Raw observations and published measurements should not be silently rewritten.

Keep:

- source
- date accessed
- original value
- uncertainty
- unit
- instrument
- publication/reference
- interpretation notes

Data provenance is part of the scientific record.

## Planned datasets

- K-dwarf host census
- transiting K-dwarf planets
- JWST exoplanet observations
- atmospheric molecular detections
- abiotic false-positive models
- Earth reference measurements

# Contributing

This project is intended to teach careful exoplanet analysis.

## Core rules

1. Separate observations from interpretations.
2. Cite primary or authoritative sources.
3. Record uncertainty.
4. Do not promote tentative detections to confirmed detections.
5. Test abiotic explanations.
6. Preserve source provenance.
7. Do not use a numerical "life score" as a substitute for evidence.
8. Update the framework when better evidence or better models become available.

## Pull requests

New data should include its source and explain what changed.

Scientific disagreements should be documented rather than hidden.

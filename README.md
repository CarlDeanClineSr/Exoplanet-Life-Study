# Exoplanet Life Study

A teaching and research framework for examining exoplanets for habitability and possible signs of life.

This repository is designed first as a **teaching tool and scientific checklist**. Live observations and newly published measurements can be added as they become available.

## Core principle

No single atmospheric gas is treated as proof of life.

The study asks whether a planet's **star, planet, atmosphere, chemistry, environment, and observations** form a persistent state that can or cannot be explained by known abiotic processes.

## Examination blocks

1. Host star
2. Planetary properties
3. Water and climate
4. Atmospheric inventory
5. Chemical disequilibrium
6. Abiotic false-positive tests
7. Persistence and repeatability
8. Independent confirmation

## Earth reference

Earth is the calibration case because life is independently established and Earth's atmosphere-ocean system exhibits strong chemical disequilibrium.

The Earth reference is not a "score." It is a measured comparison case.

## Evidence language

Each field should be labeled with one of:

- Observed
- Not detected
- Upper limit
- Tentative
- Model dependent
- Unknown
- Needs observation

Interpretation must remain separate from measurement.

## Data sources

The project is intended to connect, where appropriate, to:

- NASA Exoplanet Archive
- MAST / STScI
- JWST observations
- Gaia
- Kepler / K2
- TESS
- Hubble
- Ground-based spectroscopy
- Peer-reviewed atmospheric and photochemical models

## Project status

**Phase 1 — Framework and teaching material**

No claim is being made here that any exoplanet is inhabited.

The objective is to make the examination process understandable, reproducible, and updateable.
